# KasaColle — フロントエンドプロトタイプ

忘れ物の傘を2週間告知し、持ち主が現れなかった場合に貸出傘として循環させる、フロントエンドのみのプロトタイプです。

## 起動方法

`umbrella-prototype` ディレクトリで静的サーバーを起動します。

```sh
python3 -m http.server 4173
```

ブラウザで `http://localhost:4173` を開いてください。データはブラウザの `localStorage` に保存されます。

## 主な機能

- デモログイン（利用者 `user / user`、管理者 `admin / admin`）
- ログインした役割に応じた画面の出し分け
- 利用者は傘一覧、管理者は管理ダッシュボードを表示
- 利用者画面には忘れ物状態の傘だけを表示
- 持ち主による自己申告
- 傘の登録（名前・種類・場所・発見日・写真アップロード）
- 発見から14日経過した傘の自動貸出対象化
- 状態を「忘れ物」と「貸出」に分け、貸出内を「利用可能／貸出中」で管理
- 持ち主申告は掲示後14日間だけ表示
- 貸出・返却の状態管理
- 管理者一覧を「忘れ物／貸出」タブで切り替え
- 持ち主が見つかった忘れ物の削除
- モックデータのリセット

バックエンドや外部APIは使用していません。
